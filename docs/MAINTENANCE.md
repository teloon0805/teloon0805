## 视觉素材

配图保存在 `assets/` 中。水墨山水底景为生成绘画，字标、书法字体轮廓、构图与动画由代码单独制作；最终 SVG 内嵌底景，文字转为矢量路径，不依赖访客电脑的字体或外部图片服务。

| 文件 | 用途 |
| --- | --- |
| `hero.svg` / `hero-static.svg` | 桌面版动态与静态头图 |
| `hero-mobile.svg` / `hero-mobile-static.svg` | 窄屏版动态与静态头图 |

头图采用分层动画：双弧墨色回旋、反向笔触、水纹流动、两层不同节奏的云气与轻微入墨效果。README 中没有脚本。`prefers-reduced-motion` 会选择静态头图，手机使用单独的窄屏构图。

多波束插图左侧是程序绘制的示意地形与测线，不是真实海域或实际实验输出。右侧数字对应论文匿名真实海底案例的统一细网格几何覆盖评价，不应外推到其他海域或海上作业。

## 生成与核对

入口为 `scripts/build_assets.py`，实现位于 `scripts/build_ink_assets.py`。在 Windows 上安装 `fonttools` 后运行：

```powershell
python scripts/build_assets.py
```

脚本使用系统字体 Bodoni MT、华文行楷、楷体、方正舒体及 Consolas 生成轮廓，不复制字体文件。其他系统请修改字体路径，使用当地可用且允许用于图形制作的字体。

设计采用墨黑底、黑白雾气、银灰笔触与回旋环纹。研究主线的三组书法标题、英文与说明文字居中排版。底景使用内置图像生成工具制作，提示词与素材说明见 [ART-DIRECTION.md](ART-DIRECTION.md)。

修改后检查 GitHub 实际渲染中的图片、段落、导航锚点、折叠区域和窄屏布局。本地预览仅用于辅助核对。

公开仓库只保存主页文案、原创插图、生成代码和维护说明。原始简历、证书、私人照片、未公开论文原稿和信息核对记录留在本地。
