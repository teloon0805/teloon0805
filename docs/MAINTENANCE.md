多波束插图左侧是程序绘制的示意地形与测线，不是真实海域或实际实验输出。右侧数字对应论文匿名真实海底案例的统一细网格几何覆盖评价，不应外推到其他海域或海上作业。

## 生成与核对

源代码在 `scripts/build_assets.py`，在 Windows 上安装 `fonttools` 后运行：

```powershell
python scripts/build_assets.py
```

脚本使用系统字体 Bahnschrift、微软雅黑、Consolas 生成文字轮廓，输出 SVG，不复制字体文件。其他系统请修改字体路径，使用当地可用且允许用于图形制作的字体。

视觉由代码直接绘制，主题为深海蓝、青色光迹、海底网格、声呐扫描和 E7ian 字标，未使用图像生成模型或第三方游戏图片。

修改后检查 GitHub 实际渲染中的图片、段落、导航锚点、折叠区域和窄屏布局。本地预览仅用于辅助核对。

公开仓库只保存主页文案、原创插图、生成代码和维护说明。原始简历、证书、私人照片、未公开论文原稿和信息核对记录留在本地。
